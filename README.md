# Officina Elettrica

App web installabile (PWA) per lo studio dell'elettrotecnica e dell'automazione. Funziona offline, su Mac e Windows.

Tre strumenti in uno:
- **Logica Cablata** — schemi di comando con contattori, temporizzatori e motori; simulazione e rilevamento dei cortocircuiti.
- **Ladder PLC** — schema a contatti con scansione in tempo reale (contatti, bobine, timer, contatori).
- **Lettore CADe SIMU** — apre i file `.cad` salvati da CADe SIMU e ne ridisegna lo schema.

Tutto gira nel browser; nessun dato lascia il dispositivo.
